# Moonk@ts QB Expert Packet Lookup

A single-file interactive lookup tool for QuickBooks Online experts.

Built for fast reference during live calls — search 843 entries across 22 tabs 
including Banking Issues, Payments, Transfer Codes, Tools, Payroll, and more.

## Features
- Instant fuzzy search across all sheets
- Call Flow script pinned as the landing tab
- Transfer Codes with one-click copy
- Edit mode to add your own call scripts
- Works offline — just open index.html in any browser

## Usage
Open the link. That's it.
